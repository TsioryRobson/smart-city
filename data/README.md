# Données

Ce dossier n'est pas versionné (sauf ce fichier).

1. Télécharger le dataset : https://archive.ics.uci.edu/dataset/501/beijing+multi+site+air+quality
2. Décompresser les fichiers CSV dans `data/raw/`
   (ex. `data/raw/PRSA_Data_Aotizhongxin_20130301-20170228.csv`).

Dans le conteneur de développement, ce dossier est accessible sous `/workspace/data`.
